# Outputs

Rendered MP4s, contact sheets, and FFprobe logs from local runs go here.

These files are generated. They are not source. `outputs/` is gitignored except this note.

The proof composition itself lives in `compositions/proof_of_concept/`. Its generated teacher, B-roll, narration, and music files are also gitignored. Regenerate them with `python build_proof.py` from `saarthi_video_engine` once `ffmpeg` is on PATH.
